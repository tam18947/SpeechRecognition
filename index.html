Speech Recognition Subtitles

話した言葉をリアルタイムで大きな字幕に。必要なら翻訳も同時に表示します。

字幕を開く Open in English

すぐに使えるプリセット

  • 日本語の字幕 日本語を認識してそのまま表示
  • English subtitles Recognize English and show it as-is
  • 日本語 → 英語 英訳を大きく、原文を小さく表示
  • 英語 → 日本語 和訳を大きく、原文を小さく表示

使い方

  1. Google Chrome または Microsoft Edge で字幕ページを開きます。
  2. 画面上部の操作パネルで、話す言語と翻訳先の言語を選びます。
  3. 開始 を押し、マイクの使用を許可します。認識中は操作パネルが隠れ、マウスを画面上部に乗せると再び表示されます。
  4. 保存 で、認識した内容をダウンロードできます。形式（テキスト / SRT / VTT）は ⚙（設定）で選べます。

主な機能

  • リアルタイム字幕 — 認識途中の文字も薄く表示し、確定すると字幕として残ります。
  • 翻訳 — ブラウザ内蔵の翻訳を優先して使い、使えない場合は自分の GAS で翻訳します。翻訳文と原文を並べて表示することもできます。
  • 置換辞書 — 人名や専門用語などの誤認識を、登録した表記に自動で直します。
  • テロップ表示 — 画面下部に最新の 1〜3 行だけを表示。文字色・縁取り・背景の帯も設定できます。
  • 字幕ファイルで保存 — テキストのほか、動画編集や YouTube で使える SRT / VTT 形式で保存できます。
  • 無音で自動消去 — 最後に字幕が確定してから一定時間たつと画面をリセット。消去時に自動保存もできます。
  • 配信向けの背景 — ダーク・黒・グリーンバック・透明から選べ、OBS などに重ねられます。
  • 設定の記憶 — 選んだ設定はブラウザに保存され、次回も引き継がれます。

URL パラメータ

URL に設定を書いておくと、開いた瞬間からその設定で表示されます。OBS のブラウザソースに登録するときに便利です。

パラメータ内容例
source話す言語ja, en, ko, zh-CN …
target翻訳先の言語（none で翻訳しない）en
original翻訳時に原文も表示1 / 0
size文字サイズ（%、25〜500）300
clear無音で消去するまでの秒数（0 で無効）0, 30, 60, 120, 300
save自動消去のときに保存する1 / 0
bg背景dark, black, green, transparent
layout表示（全体 / テロップ 1〜3 行）scroll, telop1, telop2, telop3
color文字色（# は省略可）ffffff, ffeb3b
outline縁取りauto, none, thin, thick
bandテロップの背景帯1 / 0
format保存形式（カンマ区切り）txt, srt, vtt
ui表示言語ja / en

例: subtitles.html?source=ja&target=en&bg=transparent&layout=telop2&outline=thick

置換辞書と GAS の URL は URL パラメータでは指定できません。字幕ページの ⚙ から設定してください。

翻訳のしくみと GAS の用意

翻訳は次の順番で行います。

  1. ブラウザ内蔵の翻訳（Chrome の Translator API）— パソコンの中で翻訳するため、準備は不要です。言語の組み合わせごとに、初回だけ翻訳モデルをダウンロードします。
  2. 自分の GAS — 内蔵の翻訳が使えないブラウザ（Edge など）や言語の組み合わせでは、字幕ページの ⚙（翻訳の設定）に登録した GAS ウェブアプリで翻訳します。

⚙ の「優先する翻訳」で GAS を優先 を選ぶと、GAS → 内蔵翻訳の順になります。一般に GAS のほうが訳の精度が高い傾向があり、内蔵翻訳は速く、回数の上限がありません。

GAS の用意のしかた（Google アカウントがあれば無料で使えます）:

  1. Google Apps Script で新しいプロジェクトを作ります。
  2. エディタの中身を gas/Code.gs の内容に置き換えて保存します。
  3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選び、次のユーザーとして実行: 自分、アクセスできるユーザー: 全員 にしてデプロイします（初回は権限の承認が必要です）。
  4. 表示された https://script.google.com/macros/s/…/exec の URL をコピーします。
  5. 字幕ページの ⚙ を開いて URL を貼り付け、「テスト」で動作を確認してから「保存」します。

URL はそのブラウザにだけ保存され、ほかの人と共有されません。GAS の翻訳には Google アカウントごとに 1 日あたりの回数上限があります。

ご注意

  • 音声認識はブラウザの機能（Web Speech API）を使用しており、Chrome / Edge では音声がブラウザ提供元のサーバーに送信されます。
  • ブラウザ内蔵の翻訳はパソコンの中で行われます。GAS を使う場合は、認識したテキストが自分の GAS（Google 翻訳）に送信されます。
  • マイクを使うため、HTTPS または localhost で開く必要があります。
